INTRODUCTION
------------

Author of Drupal module:
* David Berneda, Steema Software (davidberneda) http://steema.com

This module enables creating charts and graphs and insert them into your
Drupal contents.

Charts are created client-side using HMTL5 Canvas and JavaScript.
No data is stored at the server, and no images are created.

INSTALLATION
------------

1. Go to Administration -> Modules.

2. Download TeeChart module from http://www.steema.us

3. Install it, enable it and save configuration.
